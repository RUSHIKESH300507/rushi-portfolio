# Rushikesh Rathod | Personal Portfolio

A responsive portfolio for a B.Tech CSE (AIML) student, built with plain HTML, CSS and JavaScript.

**Live site:** https://YOUR-PROJECT.vercel.app  *(replace after deploying)*
**Repository:** https://github.com/RUSHIKESH300507/portfolio

## Features
- Home, About, Skills, Projects, NASA achievement, Education, Resume, Contact
- Dark/light mode, animated skill bars, project filter, visitor counter
- **Working demos:** interactive car-sales dashboard (data from my Excel pivot tables) and a rule-based medical expert system
- NASA Space Apps Challenge 2025 certificate with lightbox
- Downloadable resume, reports and Excel workbook

## Technologies
HTML5, CSS3 (custom properties, grid), vanilla JavaScript, Google Fonts, Vercel.

## Run locally
```bash
git clone https://github.com/RUSHIKESH300507/portfolio.git
cd portfolio
python -m http.server 8000   # then open http://localhost:8000
```

## Structure
```
index.html   css/style.css   js/main.js   vercel.json
assets/  (certificate, resume, reports, Excel file, profile.jpg)
```

## Deploy on Vercel
1. Push to GitHub. 2. vercel.com > Add New > Project > import the repo. 3. Framework preset: Other. Deploy. 4. Paste the URL above.
